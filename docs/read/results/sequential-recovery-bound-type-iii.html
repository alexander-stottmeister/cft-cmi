Type-III sequential recovery bound: Bures distances add along a chain of von Neumann inclusions (chordal and second-order forms, no Hypothesis (U))

Status: proved — a complete structured proof. Conditional. The statement is not unconditional: it rests on U, quoted below. Read the badge only together with them.

Area: Lattice, thermal, massive and gapped geometries (O7, O9, O10) · Card type: theorem · Knowledge-base id: sequential-recovery-bound-type-iii

Statement

Let omega be a normal state on a von Neumann algebra M, N_1 subset N_2 subset ... subset N_m subset M von Neumann subalgebras with the same unit, R_k: N_{k+1} -> N_k normal unital 2-positive (Heisenberg-picture) recovery maps, R = R_1 o ... o R_{m-1}. CHORDAL FORM (Thm 12.6, thm:w6chord), no Hypothesis (U): with d_B = sqrt(2 - 2F), d_B(omega|N_m, omega|N_1 o R) <= sum_k d_B(omega|N_{k+1}, omega|N_k o R_k). Proof: telescoping through the states mu_j = omega|N_{m-j} o R_{m-j} o S_j, S_j = R_{m-j+1} o ... o R_{m-1} (steps <1>1-<1>3 of Thm 12.5, which do not use (U)), monotonicity of F under the channel S_j (Lemma 12.3, from Choi's inequality T(a^{-1}) >= T(a)^{-1} for unital 2-positive T, Lemma 12.2, via the Schur complement, and Alberti-Uhlmann 2002 Thm 2(1), p. 6, and Cor 2(5), p. 8), and the triangle inequality of d_B (Alberti-Uhlmann 2002 Prop. 1(1), p. 3, stated there without proof and attributed to Bures 1969, which is NOT OBTAINED). SECOND-ORDER FORM (Cor 12.7(2), cor:w6-second), no (U): with Phi_tot = -log F(omega|N_m, omega|N_1 o R) and Phi_k = -log F(omega|N_{k+1}, omega|N_k o R_k), Phi_tot <= (sum_k sqrt(Phi_k))^2 (1 + o(1)) as all Phi_k -> 0; if each step extends to a normal unital 2-positive map on F(I) with error check-Phi_k, then Phi_k <= check-Phi_k and the same bound holds with check-Phi_k. SATURATION, 'if' direction only (Rem 12.8, rem:w6-sat): when all corners of the protocol coincide at one point (e.g. VWZ 1(B), Protocol 3), Thm 8.5 (thm:prot3, card corner-calculus) and Theorem A give Phi_tot = Phi_A(sum_k zeta_k) = f2 (sum_k zeta_k)^2 + o and check-Phi_k = f2 zeta_k^2 + o, so the second-order bound is saturated at second order. NOT claimed: the converse (non-saturation for corners at distinct points); the document compares with the conjectural network law W2 only 'as a target, not used' (l. 1962), and W2 would at best concern the extended errors check-Phi_k. NOT claimed: the ANGLE FORM (arccos F adds along the chain; Thm 12.5, thm:w6) and its exact form Phi_tot <= -log cos(sum_k arccos e^{-Phi_k}) (Cor 12.7(1), eq:w6-master). The document proves them only under Hypothesis (U), which is refuted (card hypothesis-u-natural-cone-fidelity), so they are vacuous as proved; the conditional statement is card sequential-recovery-angle-form-under-u. The angle inequality is expected to hold without (U), but no project document proves it and no card uses it.
