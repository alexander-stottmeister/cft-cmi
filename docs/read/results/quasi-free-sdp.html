Second-order problem over quasi-free channels is a convex SDP

Status: proved — a complete structured proof.

Area: Optimality of recovery channels (O8, Phases 3 and 3b) · Card type: theorem · Knowledge-base id: quasi-free-sdp

Statement

Gauge-invariant quasi-free channels have data (X,Y), CP iff Y >= 0 and XX* + Y <= 1; in the variables (X, Z = X Q_BB X* + Y) the feasible set F = {X Q_BB X* <= Z <= 1 - X(1-Q_BB)X*} is convex and semidefinite representable, the recovered symbol is affine, and the SLD form g_Q is a convex quadratic; every local minimum is global. Caveat: g_Q is the second-order term only for defects small relative to e^{-kappa_max} (order of limits); cap weights, never drop modes.
