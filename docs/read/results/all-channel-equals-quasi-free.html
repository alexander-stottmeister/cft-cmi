All-channel second-order optimum = quasi-free SDP value

Status: proved — a complete structured proof.

Area: Optimality of recovery channels (O8, Phases 3 and 3b) · Card type: theorem · Knowledge-base id: all-channel-equals-quasi-free

Statement

Dual value sup_t Delta_z(t)_+^2/(8 V(t)) equals min_F g_Q (Sion, one compact set: F is bounded and WOT-closed because its constraints are affine positivity conditions); every channel's error is >= the dual value up to the remainder control. Numerically the exact all-channel optimum on tiny chains (one SDP over Choi matrices) is a Gaussian state to 1e-6; the relaxation is tight.
