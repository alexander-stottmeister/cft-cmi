Weak link: numerical values of the tail constants A_1 <= 2.0 and A_3 <= 0.036

Status: numerical — measured, with an error bar and a convergence order; not a theorem.

Area: Theorem A: exact recovery error of the free fermion · Card type: result · Knowledge-base id: tail-constants-numerical

Statement

The constants of the occupation-tail estimate of rigor/tail_bound.tex (Thm 4.2) satisfy A_1 = sup over kappa_c > 0 of |g1-hat(kappa_c/2 pi)| (1+kappa_c)^-1 e^{kappa_c} <= 2.0 and A_3 = sup over 0 < zeta <= 1 of zeta^-2 ||(g2)'''||_{L^1(0,inf)} <= 0.036, hence C_1 <= 0.051 and C_2 = 4 pi A_3 <= 0.46.

How to verify

rigor/tail_bound.tex Thm 4.2 (thm:tau, l. 316-330) and Sec. 9 (3) (l. 740-751): A_1 from double-precision evaluations at kappa_c = 6..25.3, A_3 from four zeta values (0.05, 0.2, 0.5, 1) assumed monotone; the document's own verdict (l. 442-449) says these values are numerical, not a closed-form estimate.
