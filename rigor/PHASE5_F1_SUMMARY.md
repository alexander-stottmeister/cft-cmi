# Phase 5, track F1 (analytic) — summary, rev. 5 (referees 1-3, F2 T4/T5, F3) (2026-09-15) — `rigor/exact_optimum_tangent_problem.tex`, 27 pp, compiles clean

1. **Chart of F (exact).** `(X,Z)∈F ⟺ N:=1-XX* ≥ 0 and 0 ≤ Y:=Z-XQ_BB X* ≤ N`; `X=(1-N)^{1/2}V` with the *polar* V a co-isometry **iff 1∉σ_p(N)** (sharp; *some* co-isometric factor exists iff `dim ker(1-N) ≤ dim ker X`), `V*=WU`, U an isometry of h_D; all defect blocks exact.
2. **Tangent problem.** `δ^(1)=δ̇+A(ζ,N_1,Y_1)` (as forms on C_c^∞; H1 upgrades it to the g_Q-norm), `A_AD=-Q_ADζ+½Q_AD N_1`, `A_DD=-(ζ*Q_DD+Q_DDζ)+½{N_1,Q_DD}-Y_1`; `δ̇=[Q,d]`, zero AA block (locality) and zero DD block (Möbius rigidity). Each datum gives *exactly* feasible channels at finite s ⇒ upper bound (given H1).
3. **Boundary-moving isometries (Thm 3.11, amended).** Bounded generators give nothing beyond S10's class (σ=0). For unbounded ones the absorption identity gives only an **inclusion** of cones, whose right-hand side is described by *how G arises* — G is the anti-symmetric part `ζ*-σ` of an admissible ζ; that G itself generates an isometry semigroup is **not** claimed (it would need `C_c^∞(D)` to be a core for ζ). Reversing it is false and fatal — `+λD_χ|_D` is anti-symmetric but generates an outward flow, and admitting it would give `T=0` (Rem 4.8); σ is the *boundary form* `⟨σg,g⟩=Re⟨ζ*g,g⟩ ≤ 0` (Lumer–Phillips, C_0-semigroup); the singular boundary N_1 are not in the g_Q-closure of the bounded ones.
4. **KKT criterion (Thm 4.4, amended).** `τ_*=E_D t_* E_D`, `M_*=½E_D(t_*Q+Qt_*)E_D`, as **quadratic forms** via `b(δ_*,·)` on a domain 𝔇 (t_* need not be Hilbert–Schmidt; λ_min may be -∞). Derivative `=½[Tr(N_1M_*)-Tr(Y_1τ_*)]`; **(a) M_*≥0 and M_*≥τ_* ⟺ (c)**; (b) `M_*≥(τ_*)_+` sufficient, stronger. **(a) is necessary but NOT sufficient**: global optimality is **(a) and (e)**, with
   **(e) `E(ζ) := 2b(δ_*, A(ζ,0,0)) ≥ 0`** for every admissible isometry generator ζ — evaluated on the **blocks** `A_AD=-Q_ADζ`, `A_DD=-(ζ*Q_DD+Q_DDζ)`; the commutator form `-2b(δ_*,[Q,ζ])` is valid **only** for bounded anti-self-adjoint ζ (where E=0) and is blind to the boundary form (F2 T5: it returns solver noise even for ζ_∞). E vanishes on the linear class and is exactly the **cyclicity anomaly** (Prop 4.3 kills `Tr([t_*,Q]ζ)`), hence a pure **boundary** functional `=½Tr((-2σ_ζ)M_*)`. Modulo the linear class the cone is generated by `ζ_0=-E_D∂_yE_D` (shift semigroup `g(y)↦g(y-a)`, i.e. `x↦1-e^{-a}(1-x)`; junction y=0) and `ζ_∞=-λD_χ|_D` (further compression; moving endpoint y=+∞). **Proved: `E(ζ_∞)=2λ(1-θ)g_Q(δ̇)>0`.** The reduction of (e) to these two directions is proved **only for vector-field generators**; multiplicity->1 shift semigroups (Cooper–Wold) and unbounded skew-adjoint `ζ=i·m(y)` outside `L̄` are admissible and escape both arguments, so the reduction of (e) to the two model directions is **Hypothesis H3** (Def 4.12, Rem 4.13, Rem 4.14). **H3 is exactly eq. (33)**: for every admissible ζ with `A(ζ,0,0) ∈ 𝔉` there are α,β ≥ 0, η ∈ L̄ with `A(ζ,0,0) = α·A(ζ_0,0,0) + β·A(ζ_∞,0,0) + η`, **read in 𝔉** — no boundary-form reformulation (that would be strictly weaker, trivially true for `ζ=i·m(y)`, and would not imply (e)). Since `A(ζ_0,0,0) ∉ 𝔉`, (33) forces **α = 0**: H3 says every feasible admissible generator is, mod L̄, a non-negative multiple of ζ_∞, so **(e) holds outright under H3** via `E(ζ_∞)>0`, and the junction test is never invoked. The content of H3 is the *exclusion* of the two non-vector-field families, not a scalar test; `E(ζ_0) ≥ 0` remains the operative test for **regularised** junction directions (finite mesh), which is what F2 T5 measures. E takes values in [-∞,+∞]: `E(ζ):=+∞` when `A(ζ,0,0)∉𝔉`, and such ζ are not feasible data — (e) is then *vacuous*, not satisfied (this is the case at ζ_0).
5. **Consistency with S10.** Stationarity on the *linear* class forces `(t_*Q)_DD=M_*` self-adjoint = condition (S) at the new point; `Σ_2→(tQ)_DD` is the N_1 condition, `Σ_1=Σ_2-t_DD≥0` the **noise** condition, `Σ_1=Σ_1*` the rotation condition. S10 (C4) is internally inconsistent with its own `S_Q(t)=δ`; correct relations `Tr(tδ)=4g_Q`, `V(t)=2g_Q` (our Lemma 1.1).
6. **θ.** Geometry-free Wiener–Hopf problem in the modular frame (`y=-log(1-x)`, `Q=(1+e^{-2πp})^{-1}`, `w(y)=-4sinh²(y/2)1_{y>0}`, kernel `K=sinh²(πΔ)/[cosh(πΔ)(cosh(πΣ)+cosh(πΔ))]`). **Numerical input (F3): θ = 0.384 ± 0.003, 1-θ = 0.616 ± 0.003**; S10's 0.300 is a taper-suppressed lower bound; `3/π²`, `1/3`, `1-2/π` all **excluded**. `θ<1` unproved (only the converse). Closed form still open.
